# Responsible use

These recipes support education, reproducible research and chemistry-model adaptation. Small fine-tuning and denoising runs do not establish real-world safety or scientific validity.

- Do not use these recipes to design or optimize harmful chemical or biological agents.
- Validate predictions independently before using them in experiments. Assess uncertainty, data leakage and performance outside the training distribution.
- Use only data you have permission to process and share. Remove credentials, personal information and confidential records from contributions.
- Preserve upstream licenses, attribution and model limitations. Report negative results as clearly as positive results.

This guidance does not change the MIT license for original code or the licenses of upstream assets. Report concerns privately to a repository maintainer; do not post sensitive details publicly.
